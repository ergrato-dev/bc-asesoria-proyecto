# Proyecto Semana 9 — Cierre del Trimestre

## 📋 Instrucciones

Con el gate Docker verificado (`2-practicas/01-taller-gate-docker-y-cierre/`), este entregable
cierra el trimestre completo:

1. El **estado final de avance** (Criterios RAP-1, RAP-3, RAP-4 en su forma consolidada): % de
   backlog completado, resultado del gate Docker con evidencia, deuda técnica documentada.
2. El **hand-off** al siguiente trimestre: qué queda por codificar, documentar o implementar.

Completa `starter/entregable-s09-cierre-final.md` con tu equipo.

## ❓ Preguntas Guía

- ¿Qué porcentaje real del backlog completo (no solo del Sprint 8) tiene código funcional detrás?
- ¿El gate Docker pasó en un clon limpio, verificado por alguien fuera del equipo (compañero o instructor)?
- ¿Qué deuda técnica queda, con qué impacto y qué prioridad para quien continúe el proyecto?
- ¿Qué necesitaría saber un desarrollador nuevo que se una al proyecto el próximo trimestre para no perder tiempo?

## ✅ Checklist de Cierre del Trimestre

- [ ] `entregable-s09-cierre-final.md` completo, sin secciones vacías
- [ ] Gate Docker superado: `docker compose up` en clon limpio levanta el proyecto completo — **sin alternativa**
- [ ] Avance ≥90% del backlog completo, medido y evidenciado
- [ ] Code review final documentado, cubriendo todo el repositorio
- [ ] Deuda técnica pendiente registrada con impacto y prioridad
- [ ] Demo integrada end-to-end ejecutada sobre la versión containerizada
