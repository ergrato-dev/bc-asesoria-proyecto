# 🎓 Glosario — Semana 9

| Término | Definición breve |
|---|---|
| **Gate de entrega** | Condición bloqueante que el Producto debe superar sin excepción — aquí, `docker compose up` end-to-end |
| **Clon limpio** | Copia recién clonada del repositorio, sin configuración manual previa ni artefactos locales |
| **Deuda técnica** | Trabajo pendiente o soluciones subóptimas, documentadas para resolver más adelante, no ahora |
| **Code review final** | Barrido de todo el repositorio del proyecto, no solo del último sprint |
| **Demo end-to-end** | Demostración en vivo de un flujo completo de usuario, de punta a punta, sobre contenedores |
| **Avance del 90%** | Meta de cierre del trimestre: proporción del backlog completo con código funcional construido |
| **Hand-off** | Documento que transfiere el estado del proyecto al siguiente equipo o trimestre |
| **Healthcheck** | Verificación automática de Docker Compose de que un servicio está realmente listo, no solo iniciado |
| **`depends_on` con condición** | Regla de `docker-compose.yml` que ordena el arranque de servicios según el estado real (no solo "ya inició") de otro |
| **Sprint Review final** | Ceremonia de cierre del trimestre, demostrada obligatoriamente sobre la versión containerizada |
| **Backlog completo** | Totalidad de historias de usuario del proyecto, no solo las del sprint actual |
| **Código muerto** | Código que ya no se ejecuta ni se usa, remanente de decisiones de diseño anteriores |
