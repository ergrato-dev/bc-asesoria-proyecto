# 🎓 Glosario — Semana 6

| Término | Definición breve |
|---|---|
| **CORS** | Mecanismo del navegador que bloquea peticiones entre orígenes distintos salvo autorización explícita del servidor |
| **Origen (origin)** | Combinación de protocolo, dominio y puerto que identifica de dónde viene una petición |
| **Estado de carga (`loading`)** | Bandera que indica que una petición a la API está en curso |
| **Estado de error** | Manejo explícito y visible de una respuesta fallida de la API |
| **Variable de entorno de frontend** | Valor de configuración (ej. URL base de la API) inyectado sin hardcodearlo en el código |
| **`.env.example`** | Archivo que documenta qué variables de entorno necesita el proyecto, sin valores reales/secretos |
| **Multi-stage build** | `Dockerfile` con varias etapas `FROM`; solo el resultado de la última llega a la imagen final |
| **Etapa de build** | Etapa del `Dockerfile` que instala dependencias y compila el código fuente |
| **Etapa de runtime** | Etapa del `Dockerfile` que sirve el resultado ya compilado, sin herramientas de desarrollo |
| **Servidor estático** | Servidor (ej. Nginx) que entrega archivos ya compilados, sin ejecutar lógica de servidor |
| **Contrato de API** | Forma acordada del payload, códigos de estado y errores que un endpoint expone |
| **Sprint Review** | Ceremonia de fin de sprint donde el equipo demuestra al instructor lo construido esa semana |
