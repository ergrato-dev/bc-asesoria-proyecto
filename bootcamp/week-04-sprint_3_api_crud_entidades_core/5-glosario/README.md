# 🎓 Glosario — Semana 4

| Término | Definición breve |
|---|---|
| **Endpoint** | Ruta HTTP concreta que expone una operación de la API |
| **Verbo HTTP** | `GET`, `POST`, `PUT`/`PATCH`, `DELETE` — la operación que expresa la petición |
| **Código de estado** | Número de 3 dígitos que indica el resultado de una petición HTTP |
| **DTO (Data Transfer Object)** | Estructura de datos de entrada/salida de un endpoint, distinta del modelo de dominio |
| **Modelo de dominio** | Entidad tal como se persiste, con todos sus campos incluidos los internos |
| **Paginación** | Entregar resultados de un listado en páginas, no todos de una vez |
| **Idempotencia** | Ejecutar la misma operación varias veces produce el mismo resultado que ejecutarla una vez |
| **CRUD** | Create, Read, Update, Delete — las cuatro operaciones básicas sobre una entidad |
| **Recurso (REST)** | Sustantivo que identifica la entidad en la ruta (ej. `/items`), sin verbos en la URL |
| **`.env`** | Archivo de variables de entorno usado para configurar la API sin hardcodear valores |
| **OpenAPI / Swagger** | Estándar para documentar de forma estructurada los endpoints de una API REST |
| **Code review** | Revisión de un PR por un compañero antes de mergear, contra `CODING_STANDARDS.md` |
