# 🎓 Glosario — Semana 7

| Término | Definición breve |
|---|---|
| **Backlog restante** | Historias de usuario del informe de diseño aún no codificadas, a 3 semanas del cierre del proyecto |
| **Vertical slice** | Caso de uso completado de punta a punta (persistencia + lógica + endpoint + frontend), usable de inmediato |
| **Horizontal slice** | Completar una capa entera (ej. todo el backend) antes de tocar la siguiente — riesgo de no dejar nada usable a tiempo |
| **Scope creep** | Crecimiento no controlado del alcance del sprint sobre lo ya priorizado en el Sprint Planning |
| **Deuda técnica** | Trabajo pospuesto a propósito para cumplir el sprint, registrado explícitamente, no olvidado |
| **Matriz impacto/esfuerzo** | Herramienta simple de priorización: impacto en el flujo core vs. esfuerzo/dependencias pendientes |
| **Milestone (GitHub)** | Agrupador de Issues de un sprint, usado para medir velocidad y avance |
| **Code review** | Revisión de un PR por al menos un compañero antes de mergear a `develop` |
| **Healthcheck** | Comando que Docker ejecuta periódicamente para decidir si un contenedor está sano/listo |
| **`depends_on` con condición** | Regla de Docker Compose que espera a `service_healthy`, no solo a que el contenedor inicie |
| **Red interna (Docker)** | Red de Compose que conecta los servicios entre sí sin exponerlos todos al host |
| **Sprint Review** | Ceremonia de cierre de sprint: qué se planificó, qué se construyó, demo y % de avance acumulado |
