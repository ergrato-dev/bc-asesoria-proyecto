# 🎓 Glosario — Semana 5

| Término | Definición breve |
|---------|-------------------|
| **Regla de negocio** | Restricción o comportamiento propio del dominio, independiente del protocolo que la dispara |
| **Capa de servicios** | Código que orquesta reglas de negocio, entre el endpoint/controlador y la persistencia |
| **Validación de entrada** | Verificación de formato o tipo de un dato recibido, antes de tocar el dominio |
| **Validación de dominio** | Verificación de una regla de negocio, realizada dentro del servicio |
| **Excepción de dominio** | Error explícito que representa una regla de negocio violada, con nombre propio (no genérico) |
| **Invariante** | Condición que siempre debe cumplirse para que un dato del dominio sea válido |
| **Regla de negocio implícita** | Regla que el negocio real necesita pero que la historia de usuario no menciona explícitamente |
| **DTO (Data Transfer Object)** | Estructura de datos usada para entrada/salida en el borde del sistema, distinta al modelo de dominio |
| **Idempotencia** | Propiedad de una operación que produce el mismo resultado si se repite más de una vez |
| **Sprint Planning** | Ceremonia de inicio de sprint que mueve historias del backlog a "Sprint Actual" |
| **Sprint Review** | Ceremonia de cierre de sprint con demo y balance de avance frente al instructor |
| **Paridad local/contenedor** | Que el código se comporte igual corriendo en local que dentro de Docker |
